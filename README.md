# عقلي AI

مساعد ذكاء اصطناعي عربي بواجهة RTL مبني بشكل مستقل باستخدام Next.js وReact وTailwind CSS، مع دعم محادثات محلية، ذاكرة، رفع ملفات وصور، صوت، نماذج Gemini، وبحث Google داخل Gemini عند تفعيل الزر.

## المتطلبات
- Node.js 18+
- مفتاح Gemini API خاص بك

## التشغيل المحلي
1. انسخ `.env.local.example` إلى `.env.local`.
2. ضع مفتاحك في `GEMINI_API_KEY`.
3. نفّذ `npm install`.
4. نفّذ `npm run dev`.
5. افتح `http://localhost:3000`.

## النشر
المشروع جاهز للاستيراد إلى أي استضافة تدعم Next.js. أضف متغير البيئة:

`GEMINI_API_KEY`

ولا تضع المفتاح داخل ملفات الواجهة أو Git.

## ملاحظات
- المحادثات والذاكرة والإعدادات تحفظ محلياً في متصفح المستخدم.
- الملفات والصور تمر عبر `/api/chat` إلى Gemini ولا يتم وضع مفتاح API في المتصفح.
- زر البحث يستخدم أداة Google Search المتاحة عبر Gemini عند تفعيلها، وتظهر مصادر الاستشهاد التي يعيدها النموذج عندما تكون متاحة.
